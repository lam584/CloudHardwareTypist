# CloudHardwareTypist (云端逐键输入助手)

Windows 本地物理键盘扫描码自动键入助手，专为无影云电脑、远程桌面、受限虚拟机等环境设计。

通过模拟真实物理键盘输入（SendInput + 扫描码驱动），无需网络传输，不依赖 Power Automate，安全、轻量且稳定。

---

## ✨ 核心特性

- **硬件级扫描码模拟**：使用 Windows `SendInput` API 与物理按键 Scan Code 驱动，兼容远程桌面及云桌面客户端。
- **自动触发与焦点感知**：
  - 复制文本后在有效期内自动监听目标应用焦点。
  - 切换到目标应用后，经过设定的等待时间自动开始键入。
- **拟人化按键延时**：内置极速、快速、自然、慢速、很慢、超慢等预设，每次按键、修饰键、回车和标点独立随机取值。
- **多重快捷控制**：
  - 双击 `Ctrl` 键或 `F8` 键手动触发键入。
  - `F9` 键紧急停止输入。
  - `F10` 键安全退出。
- **安全防误触**：支持剪贴板检测暂停与恢复、随时重置有效期、单实例运行防护。

---

## ⚙️ 默认参数说明

| 配置项 | 默认值 | 说明 |
| :--- | :---: | :--- |
| **剪贴板更新后的有效期** | `7.0` 秒 | 复制后需在此时间内切换到目标窗口 |
| **获得焦点后等待** | `4.0` 秒 | 检测到目标窗口获得焦点后的准备延时 |
| **回车后等待时间** | `4.0` 秒 | 键入换行/回车后等待下一行输入的时间 |
| **按键间隔预设** | 快速（90–190 ms） | 单字符间的拟人延时区间 |

## 🚀 快速使用

### 1. 直接运行源码
需要 Python 3.10+ 环境：

```bash
python cloud_hardware_typist.pyw
```

### 2. 打包为单文件可执行程序 (EXE)
本项目使用 PyInstaller 打包：

```bash
pyinstaller --noconfirm --clean CloudHardwareTypist.spec
```

打包完成后，可在 `dist/` 目录下获取 `CloudHardwareTypist.exe`。
