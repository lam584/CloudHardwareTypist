# CloudHardwareTypist (云端逐键输入助手)

Windows 本地物理键盘扫描码自动键入助手，专为无影云电脑、远程桌面、VMware、VirtualBox、Hyper-V、QEMU 等环境设计。

通过模拟真实物理键盘输入（SendInput + 扫描码驱动），无需网络传输，不依赖 Power Automate，安全、轻量且稳定。

---

## 💡 工作流程

1. **复制文本**：在主机复制需要输入的文本（支持剪贴板内容实时预览）。
2. **切换窗口**：在设定的有效期（默认 7 秒）内切换到目标应用窗口。
3. **焦点感知与延时**：检测到目标应用获得焦点后，等待指定时间（默认 4 秒）以确保界面就绪。
4. **自动键入**：助手自动按物理键盘扫描码逐键输入文本，并在每行回车后按设置的时间等待下一行。

---

## ✨ 核心特性

- **双通道扫描码模拟**：普通客户端使用 Windows `SendInput`；VMware 前台自动切换到兼容的传统键盘事件通道。
- **目标窗口与焦点感知**：
  - 默认自动识别无影云电脑及 VMware、VirtualBox、Hyper-V、QEMU/SPICE 虚拟机控制台。
  - 也可从预设中单独选择一种虚拟机，避免同时打开多个客户端时误触发。
  - 支持下拉选择当前系统中任意运行中的窗口作为目标。
- **拟人化按键延时**：
  - 内置极速、快速、自然、慢速、很慢、超慢 6 档预设。
  - 每次单键、修饰键（Shift）、空格、标点和回车均独立随机取值。
- **自定义等待时间**：
  - **剪贴板更新后的有效期**：可自定义在复制后多久时间内切换窗口有效。
  - **获得焦点后等待**：目标窗口获得焦点后的准备时间（默认 4 秒）。
  - **回车后等待时间**：每行输入结束回车后的停顿时间（默认 4 秒）。
- **灵活的界面控制**：
  - **停止当前输入**：一键即时中断当前键入任务。
  - **重置有效期**：重新开始剪贴板有效时间倒计时。
  - **暂停/恢复剪贴板检测**：避免日常复制其他文本时误触发。
- **字符安全校验**：
  - 严格校验标准 US/ANSI 物理键盘字符，遇到中文或不支持字符提前弹窗提示，避免乱码。
  - Windows 单实例互斥体保护，防止重复多开。

## ⚙️ 默认参数说明

| 配置项 | 默认值 | 说明 |
| :--- | :---: | :--- |
| **剪贴板更新后的有效期** | `7.0` 秒 | 复制后需在此时间内切换到目标窗口 |
| **获得焦点后等待** | `4.0` 秒 | 检测到目标窗口获得焦点后的准备延时 |
| **回车后等待时间** | `4.0` 秒 | 键入换行/回车后等待下一行输入的时间 |
| **按键间隔预设** | 快速（90–190 ms） | 单字符间的拟人延时区间 |

## 🚀 快速使用

### 1. 直接运行源码
需要 Python 3.10+ 环境：

```bash
python cloud_hardware_typist.pyw
```

在虚拟机中使用时，请先单击虚拟机控制台，让客户机真正捕获键盘。若虚拟机软件以管理员身份运行，本工具也必须以管理员身份运行，否则 Windows 会阻止跨权限级别注入按键。

### 2. 打包为单文件可执行程序 (EXE)
本项目使用 PyInstaller 打包：

```bash
pyinstaller --noconfirm --clean CloudHardwareTypist.spec
```

打包完成后，可在 `dist/` 目录下获取 `CloudHardwareTypist.exe`（单文件、无黑框控制台）。
